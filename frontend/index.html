Regras de Segurança do Firebase Firestore (Acesso Livre)
Abrir Regras no Console Firebase

Se aparecer o erro "Missing or insufficient permissions", é porque o Google bloqueia gravações por padrão no Console do Firebase. Para liberar em 20 segundos:

1. Clique no botão acima "Abrir Regras no Console Firebase".
2. Na aba Regras (Rules), substitua o texto pelo código abaixo:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

3. Clique no botão azul Publicar (Publish) no topo do Console. As permissões ficam ativas na mesma hora!
